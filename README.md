# tankwar-OOP

## Description

To start the game, after downloading the project, run this commend in the terminal or run button in IntelliJ:

```bash
mvn clean javafx:run
```
## Requirements
Run the command under tank-war folder/directory.
Make sure you have JavaFX and Maven installed on your machine.

one you're in, use W, A, S, D to move the tank, and use the space key to shoot.

Use the escape key to exit the game.
